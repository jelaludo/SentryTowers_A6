# Workshop asset pipeline

Install the pinned dependencies with `npm install` in this directory. The asset-specific packers combine static geometry within moving assemblies and retain animation controls. The matching validators check exported geometry, metadata and animation contracts.

Original character assets are built with `tools/blender/build_station_characters.py` and `tools/blender/build_kestrel.py`. Their motion previews share `workshop/circular-travel.js`; walk/run clips remain reusable in place while the optional travel mode follows a circle.

The Stålheart / MÖRK fabrication family is derived directly from existing plain GLB sources and does not require a Blender background session. It imports the exact canonical Stålheart LOD0/1/2 files, then derives twelve animated line-print bands from the matching MÖRK source; the static distance endpoint uses one wireframe line draw. No solid tank mesh is exported. Rebuild it with `node build-stalheart-mork-fabrication.mjs`; validate source hashes, canonical Stålheart parity, wireframe-only progression and decoded Meshopt exports with `node validate-stalheart-mork-fabrication.mjs`.

Recurring background units use `tools/blender/build_unit_distance_lods.py`. It produces the static one-draw intact MÖRK container/background proxy and ISAO distant-flight proxy while retaining engine-facing empty-node names. Validate both with `node tools/asset-pipeline/validate-unit-distance-lods.mjs`; these tiers do not replace articulated gameplay models at readable range.

Run `node tools/asset-pipeline/audit-library-contract.mjs` before every hand-off. It inventories every GLB and manifest, writes `docs/ASSET-AUDIT.md` plus the per-file JSON evidence, and fails when a current contract candidate has a noncanonical filename, unnamed/duplicate/dotted node, invalid or missing engine lookup, or inconsistent declared lookup set across its family. Original and legacy files remain in the report as migration debt rather than passing claims.

The coordinated Solar naming migration is reproducible with `migrate-solar-node-names.mjs`, followed by `sync-solar-lookup-nodes.mjs` and `build-solar-exports.mjs`. Its published map is `assets/solar-power/name-migration-v1.json`. Assembly candidates publish their four signed-finger replacements in `assets/assembly-line/name-migration-v1.json`; rebuilding `build-assembly-line-lods.mjs` applies those names to every damage and LOD export. `build-arrival-foundry.mjs` produces the AFR-01 detailed/game/distance family from the reusable arm and barrel sources; `validate-arrival-foundry.mjs` checks its source hashes, tiers, sockets and panel-to-barrel animation beats.
