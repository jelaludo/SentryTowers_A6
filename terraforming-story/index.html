    THE GEOGRAPHY OF THE ENDGAME

    Which orbit does what?

    The current First Light reflector constellation circles the planet. It is a prototype orbital network. A Dyson swarm would instead place many independent collectors in orbit around the star. Power would then need a transmission and receiving system back at the planet.

    So the answer is yes: the light-harvesting structure belongs around the sun. The receptors belong near the world that uses its energy. The transfer and receiver hardware are still story proposals.

    Science reference: NASA’s description of a Dyson swarm as collectors encircling a star.
