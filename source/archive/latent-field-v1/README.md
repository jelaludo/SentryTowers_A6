# LATENT v1 archive

The four viewer files in `viewer/` are byte-identical snapshots from `6312e75`, before LATENT was upgraded and renamed Senzai-KK01. Original GLBs, runtime, manifest and evidence remain under `assets/latent-field/`. Import paths in these snapshots retain their original locations; restore the original repository paths from that commit to run the old viewer. This is an archival source folder, not a separate live route.

The public `/latent-field/` route now opens `/senzai-kk01/`. All original work requires attribution to Jelaludo. See the repository ASSET-LICENSE.md.
