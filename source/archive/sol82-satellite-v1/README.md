# Preserved SOL-82 satellite / 15 September 2026

This folder preserves the original satellite family before the owner-approved Syzygy redesign on 17 September 2026. Original GLBs, optional Meshopt derivatives, manifest, runtime notes, generator, validator, render script, Blender source and poster are retained unchanged.

The scripts retain their original project-relative paths. To reproduce this historical version, use a separate checkout and restore its scripts and files to their former locations; do not run them in this archive directory. Current authored exports live in assets/sol82/ at the repository root.
