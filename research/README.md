# Base construction research

- [Individual asset catalog](base-assets.md): 109 planned asset types, plots and placement purposes.
- [Assembly and destruction rules](base-assembly-rules.md): modular connections, district logic, generation order, four structural states, dependency graphs, spherical-board adaptation and production scope.
- [Structured catalog](base-assets.json): stable IDs, planning footprints, sample border connectors, damage profiles and authoring requirements.

This is a design package. No base models or procedural base generator have been built yet. JSON connector examples are not a fully validated runtime prefab manifest. The existing sentry GLBs are intended to attach to the proposed emplacement modules; they still need their own destruction variants.
